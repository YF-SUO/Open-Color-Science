# Open-Color-Science
An open course on Color Science, from optics and human vision to CIE 1931, color spaces, HDR, and color management. I want to turn this into an ever-evolving "open-source textbook," hoping it will eventually become a Open-Color-Science textbook that anyone can learn from, read, and contribute to.
——关于色彩科学的开放课程，从光学和人类视觉到 CIE 1931、色彩空间、HDR 和色彩管理。我想把它变成一本不断发展的“开源教科书”，希望它最终能成为一本任何人都可以学习、阅读和贡献的开放色彩科学教科书。
