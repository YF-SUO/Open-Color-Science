

# Open Color Science

> **An open course for learning Color Science — from light and human vision to CIE 1931, color spaces, HDR, and modern color pipelines.**

---

## 📖 About

**Open Color Science** is an open-source educational project dedicated to building a clear, structured, and accessible learning path for Color Science.

Rather than collecting scattered notes, this project aims to organize knowledge into a complete course that connects the history, science, mathematics, and engineering behind modern color technology.

Whether you are a student, engineer, researcher, or simply curious about how color works, this course is designed to help you understand not only **what** the standards are, but also **why** they were created and **how** they are used today.

---

## 🎯 Learning Goals

By following this course, you will gradually understand:

* 🌈 How light produces color
* 👁️ How the human visual system perceives color
* 📜 Why the CIE 1931 standard was established
* 📐 How color can be represented mathematically
* 🖥️ How displays reproduce color
* 🎥 How digital images and videos manage color
* 🌍 How modern color management systems work

## 🧪 Learning Philosophy

This project follows a simple principle:

> Learn every concept by understanding **its history**, **its motivation**, **its mathematical foundation**, and **its practical application**.

Instead of memorizing standards, we learn why they exist.
