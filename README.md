# Open Color Science

A structured open course on Color Science — from human vision to modern color pipelines.

---

## 🎯 What is this?

This project is an open, structured learning path for understanding color science.

It starts from:

- Human vision system
- Light and perception
- CIE 1931 standard

and gradually moves to:

- Color spaces (RGB, XYZ, Lab)
- Display technologies
- Image & video color pipelines
- HDR systems
- Color management (ICC, OCIO)

---

## 🧭 Learning Path

### 01 - Why Color Science Exists
Understanding why we need a scientific model of color.

### 02 - Human Vision System
How the eye perceives light and color.

### 03 - Light & Spectrum
Physical basis of color.

### 04 - CIE 1931 Standard
The foundation of modern color science.

### 05 - Color Spaces
RGB, XYZ, Lab, xyY.

### 06 - Display Systems
How screens reproduce color.

### 07 - Image & Video Color
YUV, BT.709, BT.2020.

### 08 - HDR Systems
PQ, HLG, Dolby Vision.

### 09 - Color Management
ICC, OpenColorIO, ACES.

---

## 🧪 Goal of this project

To build a clear, intuitive, and structured understanding of color science
that connects physics → perception → engineering → industry standards.
